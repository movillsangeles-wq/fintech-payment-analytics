# Corporate Card Portfolio & Unit Economics Analyzer

A lightweight Python & SQL tool designed to analyze premium corporate card portfolios (e.g., Black Cards), evaluate interchange margins, rewards program costs, credit risk exposure, and customer lifetime value (LTV) across B2B cohorts.

## Features
- **P&L Unit Economics Simulation:** Calculates net interchange revenue minus reward program liabilities and funding costs.
- **Cohort Activation & Retention Tracking:** Evaluates active user engagement and transaction volume over a 12-month lifecycle.
- **Risk & Credit Buffer Modeling:** Analyzes utilization rates and dynamic credit limit thresholds to mitigate default risk.

## Tech Stack
- **Language:** Python 3.10+
- **Libraries:** Pandas, NumPy, SQLAlchemy
- **Data Source:** SQL Queries connected to Metabase / DWH
